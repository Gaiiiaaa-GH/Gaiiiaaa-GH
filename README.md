## Projects

<img align="right" width="170" src=".github/assets/cipher-coins.png" alt="Cipher">

- **[STARRAILdle](https://github.com/Gaiiiaaa-GH/STARRAILdle)** — daily Honkai: Star Rail character-guessing game, in French and English. [Play it](https://starraildle.vercel.app)
- **[Gaiiiaudio](https://github.com/Gaiiiaaa-GH/Gaiiiaudio)** — per-tab volume mixer for Chromium browsers, with per-domain rules.
- **[Gaiiiablox](https://github.com/Gaiiiaaa-GH/Gaiiiablox)** — multi-account manager for the Roblox Windows client.
- **[PurgeMyMessages](https://github.com/Gaiiiaaa-GH/PurgeMyMessages)** — Vencord plugin that deletes your own Discord messages in bulk.
- **[NasusBeatbox](https://github.com/Gaiiiaaa-GH/NasusBeatbox-releases)** — League of Legends account manager for Windows (downloads only).
- **[STARRAILdle-Assets](https://github.com/Gaiiiaaa-GH/STARRAILdle-Assets)** · **[ZZZdle-Assets](https://github.com/Gaiiiaaa-GH/ZZZdle-Assets)** — clean Honkai: Star Rail and Zenless Zone Zero art and icons.
